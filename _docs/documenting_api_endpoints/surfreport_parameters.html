Parameters

Path parameters

Path parameter Description
{beachId} The value for the beach you want to look up. Valid beachId values are available from our site at sampleurl.com.

Query string parameters

Query string parameter Required / optional Description Type
days Optional The number of days to include in the response. Default is 3. Maximum is 7. Integer
units Optional The units for the response. Use imperial for feet, knots, and Fahrenheit, or metric for centimeters, kilometers per hour, and Celsius. Default is imperial. String
time Optional If you include the time, only the conditions for that hour are returned in the response. Integer. Unix time (seconds since January 1, 1970) in UTC.
